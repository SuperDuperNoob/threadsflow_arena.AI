### Tier B/C — must be sourced from platforms or human-controlled accounts

Tier definitions:

- **Tier B — Bootstrapped:** an agent can consume or operate with the resulting scoped token/key, but a human must create the first account/root token or approve the platform resource.
- **Tier C — Human-only:** acquiring the credential crosses identity, consent, billing, App Review, or ToS-sensitive boundaries. The agent must not attempt it from scratch.

## Credentials intentionally not sourced externally

- n8n API keys are not needed for deployment. `scripts/bootstrap_n8n.sh` uses the n8n CLI and internal owner setup (`scripts/bootstrap_n8n.sh:82-160`).
- GitHub credentials are not required for the public clone path used by `scripts/setup_new_vps.sh:98-103`.
- There is no code-backed `/api/config/system/:key` or five-tab settings board credential surface in the current repo.
